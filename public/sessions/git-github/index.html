Suivre · Partager · Collaborer

Une organisation claire pour les projets d’équipe.

À mesure qu’un projet évolue, il est utile de comprendre ce qui a changé, de conserver les étapes et de coordonner le travail. Cet atelier présente Git et GitHub comme des outils de suivi et de collaboration.

01

Comprendre les versions

Découvrir pourquoi conserver l’historique des changements facilite le suivi d’un projet.

02

Organiser son travail

Se familiariser avec les notions de dépôt, de modifications et de contribution à un projet.

03

Collaborer avec GitHub

Découvrir comment une plateforme partagée peut aider une équipe à coordonner ses contributions.
